# 文本、滑块、表格组件测试用例

## 测试范围

本文覆盖 Museboard 画板结构化组件中的文本组件、滑块组件、表格组件。测试目标是确认组件渲染、编辑、结构化数据写回、运行态限制和关键边界行为符合产品原则：对话区只承载短消息，真实工作成果必须落在画板 Workspace JSON 的结构化节点上。

## 自动化测试

自动化测试由 Codex 执行，覆盖组件级核心行为。运行命令：

```bash
npm run test
```

| 编号 | 组件 | 场景 | 自动化断言 |
| --- | --- | --- | --- |
| AUTO-TEXT-001 | 文本 | Markdown 预览渲染 | 标题按 heading 渲染，正文内联 Markdown 可见。 |
| AUTO-TEXT-002 | 文本 | 双击进入编辑并提交 | textarea 展示组合后的 Markdown；失焦后 `props.title` 和 `props.text` 写回 workspace。 |
| AUTO-TEXT-003 | 文本 | Escape 取消编辑 | 草稿内容不写回，原 `props.title` 和 `props.text` 保持不变。 |
| AUTO-SLIDER-001 | 滑块 | 基础属性渲染 | range input 的 `min`、`max`、`step` 与节点 props 一致。 |
| AUTO-SLIDER-002 | 滑块 | 值变更预览 | input 事件更新 `props.value`，并进入用户编辑暂存状态。 |
| AUTO-SLIDER-003 | 滑块 | 值变更提交 | blur 后用户编辑完成，历史栈记录一次可撤销变更。 |
| AUTO-TABLE-001 | 表格 | 表头与单元格渲染 | columns 和 rows 以结构化 input 渲染。 |
| AUTO-TABLE-002 | 表格 | 单元格编辑 | 修改单元格后写回 `props.rows[row][column]`。 |
| AUTO-TABLE-003 | 表格 | 右键插入行列 | 通过单元格菜单插入行、列后，`props.rows` 和 `props.columns` 尺寸同步增长。 |
| AUTO-TABLE-004 | 表格 | 合并与拆分单元格 | 右键合并生成 `props.merges`；拆分后 `props.merges` 清空。 |

## 手动测试

手动测试由你执行，建议在开发服务中打开：

```bash
npm run dev -- --port 5173
```

访问 `http://127.0.0.1:5173/`。

| 编号 | 组件 | 前置条件 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- | --- |
| MANUAL-TEXT-001 | 文本 | 画板中存在文本节点 | 双击文本节点，修改标题和正文，点击节点外部 | 节点显示新标题与正文；右侧对话区不出现长篇结果。 |
| MANUAL-TEXT-002 | 文本 | 文本节点处于编辑态 | 输入 Markdown 列表、加粗、行内代码，提交 | 预览格式正确；内容仍作为文本节点 props 保存。 |
| MANUAL-TEXT-003 | 文本 | 文本节点处于编辑态 | 修改内容后按 Escape | 编辑取消，节点内容恢复编辑前状态。 |
| MANUAL-TEXT-004 | 文本 | 顶部模式可切换 | 切换到运行态后尝试编辑文本 | 文本不能进入编辑态或不能写回变更。 |
| MANUAL-SLIDER-001 | 滑块 | 画板中存在滑块节点 | 拖动滑块到新值并松开 | 当前值显示更新；相关绑定节点随变量变化刷新。 |
| MANUAL-SLIDER-002 | 滑块 | 选中滑块节点 | 在属性面板修改最小值、最大值、步长、单位 | 滑块轨道范围和值显示符合新配置。 |
| MANUAL-SLIDER-003 | 滑块 | 滑块已改变过 | 使用底部工具栏 Undo/Redo | 滑块值可撤销、可重做，画板显示同步。 |
| MANUAL-SLIDER-004 | 滑块 | 设置 `min > max` 或非默认 step | 拖动滑块到边界位置 | 值被限制在有效边界内，不出现 NaN 或 UI 卡死。 |
| MANUAL-TABLE-001 | 表格 | 画板中存在表格节点 | 修改表头和多个单元格 | 表头、单元格内容即时显示并保留在表格节点中。 |
| MANUAL-TABLE-002 | 表格 | 表格中至少一行一列 | 右键行控制柄，插入行、上下移动行 | 行数量与顺序符合操作结果，其他列数据不错位。 |
| MANUAL-TABLE-003 | 表格 | 表格中至少两列 | 右键列控制柄，插入列、左右移动列 | 列数量与顺序符合操作结果，每一行列值同步移动。 |
| MANUAL-TABLE-004 | 表格 | 表格中存在相邻单元格 | 右键单元格，向右或向下合并，再拆分 | 合并区域显示为一个单元格；拆分后恢复普通单元格。 |
| MANUAL-TABLE-005 | 表格 | 表格中存在多行多列 | Shift 选择多个单元格后右键合并选区 | 选区范围正确，高亮清晰，合并后无内容异常丢失。 |
| MANUAL-TABLE-006 | 表格 | 表格已编辑 | 使用 Undo/Redo | 行列编辑、合并拆分可以按步骤撤销和重做。 |
| MANUAL-LAYOUT-001 | 三组件通用 | 页面已加载 | 检查画板、右侧对话栏、属性面板位置 | 右侧栏只包含对话窗口；属性面板悬浮在画板内且可收纳。 |
| MANUAL-AGENT-001 | 三组件通用 | 对话输入框可用 | 输入短指令，让 Agent 新增或修改文本、滑块、表格 | 对话区只显示短消息和变更预览；画板节点被结构化更新。 |

## 通过标准

- 自动化测试全部通过。
- 手动测试中无空白页、明显控制台错误、布局错位或不可恢复交互。
- 组件变更必须写回 Workspace JSON 中对应节点的 props，不允许退化为截图、任意 HTML 或脚本。
